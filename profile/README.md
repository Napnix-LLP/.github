# Napnix

**CRM, lead follow-up and custom software for service businesses.**

Napnix builds the systems behind lead capture, automated follow-up, CRM and
operations for agencies and service businesses — NapCRM off the shelf where it
fits, custom software where it doesn't. Based in Sahibzada Ajit Singh Nagar
(Mohali), Punjab, India, working with clients across India and abroad.

- 🌐 Website: **[napnix.in](https://napnix.in)**
- 🧩 NapCRM — industry CRM with lead management, automation and multi-channel messaging: [napnix.in/napcrm](https://napnix.in/napcrm)
- ✉️ NapMail — email delivery with SMTP rotation and anti-spam scoring
- 🛠️ Services — web, mobile, cloud, and AI/ML: [napnix.in/services](https://napnix.in/services)

Stack: React · Next.js · Node.js · Flutter · AWS
